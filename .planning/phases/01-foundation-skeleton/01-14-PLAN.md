关闭 `01-VERIFICATION.md` frontmatter `gaps[0]` 记录的唯一 blocker：`scripts/check-secrets.sh` 的关键词分支要求值**带引号**，于是 `.env` / YAML / TOML / shell / justfile / GitHub Actions `env:` 里未加引号的赋值**整类不可见**——恰好是成功标准 4「代码与**配置**中无明文密钥」里「配置」那一半，也恰好是本项目自己的第二个密钥 `mcp_bearer_token`（一串没有任何供应商前缀的随机值）在配置文件里的形态。

Purpose: 成功标准 4 的自动化证据链目前建立在一条看不见目标格式的正则上。这是**证据缺口不是现行泄漏**——verifier 与两轮评审用三组独立更宽的检索确认当前仓库零明文密钥。因此本 plan 只改扫描器与它的 selftest，不涉及任何产品代码；唯一被动到的产品文件是一条撞上加宽后正则的测试 fixture。
