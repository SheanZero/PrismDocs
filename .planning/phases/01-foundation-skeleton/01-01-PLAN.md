<objective>
建立 PrismDocs 的单一 cargo workspace 骨架，并用一条真实端到端通路证明架构形状成立：
用户在页面上点一下 → Tauri 命令 → prism-engine facade → prism-store → 真实 SQLite → 值回到页面。

Purpose: 本阶段的五项不可逆决策全部建立在「shell 薄、engine 厚、依赖单向」这一形状上。
先用最薄的一条真路把这个形状钉住（tracer），再横向铺开其余 crate，可以在第一个 commit
就暴露 workspace 布局 / 版本 pin / IPC 契约的架构性错误，而不是在 Phase 4 才发现。

Output: 根 Cargo.toml（含全部 workspace.dependencies pin）、9 个 engine crate + src-tauri +
React 前端骨架、一条可运行的 `dev_ping` 端到端通路。
</objective>
